# 入境服务凭证争议台

本服务用于多语言服务异议、代理关系和调解决定。仓库提供可启动的健康检查、SQLite 迁移入口和最小测试，领域功能将在这些约定上持续建设。

## 领域资料

核心记录包括：游客别名、凭证摘要、案件、代理授权、材料披露、调解决定、金额账项、期限。

疑似重复只能人工合并；授权撤回阻止代理查看新材料；金额更正追加记录；期限按服务发生地时区计算。

## 本地命令

执行 ./scripts/migrate 可重复应用数据库迁移；执行 ./scripts/test 运行自动化测试；执行 ./scripts/start 启动 HTTP 服务。数据库默认写入 data/visitor_dispute.sqlite3，也可通过 DATABASE_PATH 指定其他路径；监听地址由 HOST 和 PORT 配置。

Docker 镜像构建后使用相同的迁移与启动入口，运行期间不需要外部数据库、缓存或消息服务。
